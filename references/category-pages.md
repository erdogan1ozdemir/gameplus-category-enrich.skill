# Gameplus GFN Category Pages

All 27 category pages live under `https://gameplus.com.tr/gfn/oyunlar/*`. Each has a primary keyword the content should target and adjacent categories that make natural internal-link partners.

When writing a category content piece:
1. Find the target page in the table below.
2. Note its **primary keyword** and **suggested secondary keywords** (these are starting points; confirm via DataForSEO in Phase 2).
3. Pick **3-4 adjacent categories** from the "natural link partners" column as internal-link targets, contextually relevant.

## How to pick internal-link partners

For a given category page, choose 3-4 from its "natural link partners" column based on:

1. **Topical relevance.** Does it make sense in a sub-genre paragraph? Example: when writing the MMO content, MMORPG mechanics naturally lead to a mention of RPG (canlandirma) and strategy MMOs (strateji).

2. **Cross-funnel diversity.** Don't link only to other genre pages. Include 1-2 cross-cutting links — typically `/gfn/oyunlar/oynamasi-ucretsiz` (free-to-play) since most genres have free entries, and either a platform page (/steam, /epic-games) or another genre.

3. **Anchor-text variety.** If you've already used "FPS oyunları" as an anchor in the body, you don't need to repeat that anchor in the H4 about FPS games — that section is its own internal context. Use the link in a different sub-section.

4. **No reciprocal link spam.** If you're writing the action page and you link to FPS, the FPS page should not have to link back to action in every section. Strong topical hubs survive on a few quality links, not link wheels.
