# URL → Anchor Text Mapping

Canonical anchor text choices for every internal link. Use this table every time you write a link. When in doubt, pick the **bolded** "preferred" option below; the rest are valid alternates that let you vary anchors across multiple content pieces on the same domain.

## Why this matters

Anchor texts are a primary signal to Google about what the destination page is about. If 100 Gameplus pages all link to `/gfn/paketler` with the anchor "buraya tıkla", the destination ranks for "buraya tıkla", not "geforce now fiyat". By consistently linking with keyword-aligned anchors, we strengthen the destination's ranking for those keywords.

The mapping below was supplied by the Gameplus team. Stick to it.

## Revision history notes

Things the Gameplus team specifically asked to change in past revisions:

| Anchor we tried | What they wanted instead | Reason |
|---|---|---|
| "GAME+ paketi" → /gfn/paketler | "GeForce NOW fiyat" | GeForce NOW is the searched brand, GAME+ is internal naming |
| "GeForce NOW GAME+" → /gfn | "GeForce NOW" or "NVIDIA RTX destekli bulut sunucuları" | Shorter, more descriptive |
| "bağımsız yapımlar" → /gfn/oyunlar/bagimsiz | "indie oyunlar" | More search-friendly Turkish |
| "MMO başlıklar" → /gfn/oyunlar/mmo | "MMO oyunlar" | "başlık" is banned in body (see style-guide) |
| "macera kategorisi" | "macera oyunları" | "kategori" reads like internal navigation |

If a future revision changes one of these, update this file.
